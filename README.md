# COVID-19 X-Ray Classifier -- Web Application

Client-side chest X-ray classifier using TensorFlow.js and OpenCV.js WASM. See the [project README](../README.md) for full documentation.

## Quick Start

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- TensorFlow.js 4.22
- OpenCV.js (WASM)
- Radix UI
- GitHub Pages
